03 / Math / Algorithm Used

Math / Algorithm Used

No numeric formulas in this phase The only "logic" is the key-resolution algorithm in load_text(lang): for each of 20 simple keys, 4 six/three-item list keys, and 5 decoder-row plain-language labels, look up the corresponding terminology-map.json entry; if absent or literally the string "UNTRANSLATED", add it to a missing-keys list; after processing every key, if that list is non-empty, print it and exit 1 — otherwise return the fully-overlaid text structure. m6_levers is explicitly excluded (sourced from spine-s1.json, not this map).

06 / Limitations / Second-Best Alternative

Limitations / Second-Best Alternative

  • 31 of 43 (VI) / 33 of 43 (ZH) entries are honestly UNTRANSLATED — this phase deliberately did not invent translations for the new Oct-2026 slide sentences, per ASM-007. That work is scoped to happen after content freeze, by a qualified speaker, using this map as the vocabulary starting point.
  • Second-best alternative (rejected): approximate the untranslated deck sentences using the differently-worded VI/ZH chart captions already in build_teaching_visuals.py (e.g. its own m1_title/m5_title, which say something similar but not identical). Rejected — a paraphrase presented as a sourced translation would be worse than an honest gap, since it could silently ship wrong wording under a false "trust: verified" label.
  • The fresh-viewer test and the timed solo dry-run remain genuinely human-only — this phase only lowers the activation energy to schedule them, it cannot substitute for a real person sitting through the session.
