02 / Background & Objective

Background & Objective

The repo teaches Vietnam's Direct Power Purchase Agreement (DPPA) settlement mechanics through a live app, a slide deck, facilitator guides, and a printed handout, all of which must agree on the same VND/kWh figures. A July 2026 hardening sprint made the deck pipeline trustworthy: app/src/modules/settlement.js computes every figure, JSON exports are the interface, and CI regenerates and diffs them (deck-parity). That sprint's own after-action review (this plan's originating brainstorm) found the sprint had stopped short: three prose documents still stated a retired headline figure, and the printed handout — plus ~76 other hand-typed figures across 15 prose files — had no verification at all.

Phases 1–2, executed earlier on 2026-07-17, fixed the live stale references and built a permanent CI denylist so a retired figure can never silently reappear. This report covers Phases 3–5: extending the engine's JSON export contract to the two scenarios it didn't cover, wiring the handout builder to that contract, building the second CI gate that catches any unaccounted-for large figure (not just previously-retired ones), and closing the plan's two research gaps (regulatory source URLs, an FMP proxy series).

05 / Methodology

Methodology

Each phase followed the same discipline: implement, run the closest available check, fix any red result before committing, then commit with a descriptive message — never committing red. For the two new CI gates specifically, "passing once" was not treated as proof; each was validated with a planted-failure drill — a known-bad value was temporarily introduced into a real repo file, the checker's failure output was confirmed to name the exact file and line, and the change was reverted with a zero-residue diff. For the handout regeneration, correctness was proven by extracting and diff-comparing the paragraph and table text of the old and newly-generated .docx files, accepting binary-level differences (fonts, XML structure) as expected noise while requiring textual content to be exactly identical.

06 / Phase-by-Phase Analysis

Phase-by-Phase Analysis

Phase 1 — Stale-Reference Hotfix (prior, same-day)

Fixed three living documents still stating the retired "0 of 56" gate-sweep result; committed untracked planning docs; pruned an empty nightly branch. Confirmed clean via a repo-wide grep sweep.

Phase 2 — Retired-Figures Denylist (prior, same-day)

Built tools/check_retired_figures.py and its config, wired into CI, proved it fails on a planted stale figure and passes clean otherwise. Established the pattern this report's new gate extends.

Phase 3 — S2/S3 Spine Exports

Refactored export-spine.mjs around a new buildSpinePack(scenarioKey) function. S1's output is byte-identical (verified by git diff --exit-code); S2 and S3 packs are new, each with six hard anchor assertions matching the plan's specification table exactly (e.g. S2 cEvn = 19,628,262,400; S3 cfd = 750,000,000). Added six vitest cases covering all anchors plus a rejection test for an unknown scenario key. The exporter's main() was also guarded to run only when invoked as a script (not on import), so the new vitest suite can import buildSpinePack without triggering file writes as a side effect.

Phase 4 — Handout Generation & Prose-Figures Verifier

Rewired build_worksheet_answer_docx.py to load the three spine JSONs and format every scenario total, comparison-table cell, and the S3 excess block from them — module-level assertions refuse to build from drifted spines. A grep for the six previously-hardcoded totals now returns zero matches. Built tools/verify_prose_figures.py: it collects every ≥7-digit figure the engine exports, scans living prose for comma-grouped tokens, and fails on anything not in that canonical set or an explicitly justified literal. A necessary refinement discovered during triage: the token regex was initially matching unrelated comma-separated numbers inside inline chart-data <script> blocks and SVG-coordinate HTML comments (e.g. a Chart.js data array), so both are now stripped (preserving line numbers) before scanning — a false-positive class the plan did not anticipate. After that fix, 15 genuine literals were triaged and justified with reasons (a negotiation hypothetical, two intentional wrong-answer quiz distractors, a derived-but-not-exported S2/S3 sub-figure, and a pre-existing separate illustrative case table), and two apparent near-misses were confirmed to be deliberate pedagogical distractors rather than stale drift.

Phase 5 — Sourcing Gaps & Human-Blocked Register

Located and confirmed the official-gazette text of both cited regulations (Decree 57/2025/NĐ-CP, issued 2025-03-03; Circular 16/2025/TT-BCT, issued 2025-02-01, amended by Circular 36/2025/TT-BCT). For the FMP proxy series, no raw NSMO/ERAV dataset was found — the gap is documented as bounded, not silently left open — but two dated, sourced period averages were located (1,423.5 VND/kWh for early 2024; 1,255 VND/kWh for Q1 2026), bracketing the app's illustrative 1,427 figure. Added a five-item human-blocked register to the October readiness checklist and cross-linked it from NOTES.md.

07 / Findings & Recommendation

Findings & Recommendation

Finding 1. The last unguarded number surface in the repo — the printed handout — is now generated, not typed, closing the same class of risk the deck pipeline closed months earlier for a document that cannot be hot-fixed once printed.

Finding 2. A denylist alone (Phase 2) only catches figures someone remembered to retire. The new prose-figures verifier (Phase 4) is a stronger net: it fails on any unaccounted-for large figure, including ones nobody flagged yet — verified by a planted one-digit drill that the checker caught and named precisely.

Finding 3. Two figures in the deck's teaching narrative look like typos at a glance (8,263,196,000 in lessons/0007; 20,428,262,400 in lessons/0008) but are deliberate wrong-answer quiz distractors — the triage rule ("differs by a few digits → fix, don't allowlist") correctly does not apply to values explicitly labeled as wrong. This is recorded with reasons in tools/prose_figure_literals.json rather than "fixed," since there was nothing broken.

Recommendation. Proceed to Phase 6 hygiene review of this plan's own companion coordination contract (retired-figures notes field) once the gate-credibility plan's gate-sweep rework lands and retires "5 of 56" — that hand-off is already documented in this plan's Gotchas section and requires no new design work, only execution when the time comes.
