4. Math / Algorithm Used

The constrained FMP generator centers a normalized version of the existing daily shape on the market-price midpoint (so the slider still moves it), with amplitude bounded by the midpoint↔strike gap so it cannot cross strike:

amp     = min(midpoint × 0.15, |strike − midpoint| × 0.8)
norm[h] = (FMP_SHAPE[h] − mean(FMP_SHAPE)) / maxDev      // ≈ [−1, +1]
value   = midpoint + norm[h] × amp
side 'below' → value = min(value, strike − 2%·strike)
side 'above' → value = max(value, strike + 2%·strike)

For the deck defaults (gap = 100), amp = 80, giving Workshop 1 ≈ 1,092–1,225 (all < strike 1,250) and Workshop 2 ≈ 1,542–1,680 (all > strike 1,500).

7. Limitations / Second-Best Alternative

  • The chart is illustrative: per-hour figures do not sum exactly to the monthly 5-line bill (the bill is authoritative). A caption clarifying this is scheduled in PHASE-02.
  • If a presenter drags marketPrice across strike on a workshop preset, the side-of-strike guarantee compresses the curve toward the margin rather than crossing — an extreme manual value flattens it slightly.
  • Second-best: vary only load/solar and keep FMP flat — rejected, as it leaves a dead-flat FMP line the user explicitly disliked.
