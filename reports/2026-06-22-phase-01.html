Math / Algorithm Used

Loss-factor derivation

The app previously folded a single empirical scalar 1.027263. The correct split per Decree 57/2025 is two separate regulatory coefficients:

k   = 1.026    // price conversion: generator-meter FMP → buyer-side price
K_pp = 1.008   // volume/loss conversion: generator-meter kWh → buyer-credited kWh (≥22–<110 kV)

Combined lossFactor = k × K_pp = 1.026 × 1.008 = 1.034208 → rounded to 1.0342

The previous value 1.027263 equals neither coefficient nor their product — it was an approximate empirical constant inherited from an earlier teaching model iteration.

Retail tariff anchoring

EVN raised the average retail price twice in 2024-2025. The chain:

Oct 2024 adjustment → 2,103.12 VND/kWh
10 May 2025 (+4.8%) → 2,204.07 VND/kWh   ← Decision 599/QD-EVN (verified primary source)
App default updated to nearest integer:   2,204

Limitations / Second-Best Alternative

FMP remains illustrative. The deck's ~1,427 VND/kWh is a 2025 teaching reference, not a published NSMO/ERAV average. The correct value requires primary data from Vietnam's National Power System and Market Operator (NSMO) or ERAV. Until that source is provided, both the app and deck should label FMP as "illustrative."
DPPA fee values (360 / 163.3 VND/kWh) are derived from EAVCED public training material, not a named EVN annual notice. Decree 57 requires EVN to announce these annually on the electricity-market website; the 2025 notice text was not retrieved during research. These values are plausible for 2025 but should be re-sourced before being presented as authoritative.
Alternative approach considered: "Keep current defaults, focus on structure only" (plan Grill Me Q-002 option). Rejected — calibration drift between docs and code was the primary defect; fixing structure without fixing numbers would leave a false impression of correctness.
Kpp string tests: The ui.test.js assertions were refactored to use lossFactor.toFixed(3) dynamically rather than hardcoding 1.027. This prevents the same breakage if lossFactor changes again. The minor cost is one extra line of test setup per assertion.
