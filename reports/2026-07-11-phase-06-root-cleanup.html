06 / Limitations / Second-Best Alternative

Limitations / Second-Best Alternative

  • build-deck.js (a root-level legacy deck builder, superseded by the Python build scripts, referenced from package.json's main field but not wired to any npm script) still references desktop-current.png. Rather than judging it dead code and deleting it — a call the plan's ASM-008 explicitly reserves for a future phase, not this deletion-only cleanup — the referenced image was kept. This is a conservative, reversible choice: the file costs nothing to keep and the alternative (declaring legacy code dead without the user's sign-off) is exactly the kind of unauthorized judgment call the project's own guidelines warn against.
  • Second-best alternative (rejected): delete all 81 candidate files unconditionally, since the plan's brainstorm called them "superseded." Rejected because the plan's own TASK-06-03 explicitly requires resolving any live-reference hit before committing — a blanket deletion would have shipped a broken reference in a script that, legacy or not, still exists and still runs if invoked.
07 / Errors / Warnings / Flags

Errors / Warnings / Flags Encountered

  • First reference-check grep produced ~64 KB of noise (matches inside .playwright-mcp/*.yml session recordings, where phrases like "selected-hour load" matched the pattern as plain English, not as filenames). Refined the regex to require a literal .png suffix, which correctly surfaced only the 2 real hits and eliminated the false positives.
  • Rebuilding the deck as a build-script sanity check produced an incidental binary diff in the tracked .pptx (PowerPoint zip containers are not byte-deterministic across rebuilds even with identical logical content). Reverted with git restore since PHASE-06 is scoped to deletions only — this diff did not belong in this phase's commit.
  • No test, lint, audit, or parity failures. Full battery green after cleanup: deck audit PASS, parity PASS, vitest 51/51, eslint clean, playwright e2e 27/27, production build clean.
